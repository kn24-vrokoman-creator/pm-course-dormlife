# DormLife

**DormLife** — вебзастосунок для мешканців гуртожитку №10 НУБіП України, створений для покращення комунікації, доступу до важливої інформації та вирішення побутових питань.

## Мета проєкту

Створити єдиний цифровий простір для мешканців гуртожитку №10, у якому студенти зможуть отримувати оголошення, спілкуватися, повідомляти про несправності та стежити за актуальними подіями.

## Основні можливості

- Реєстрація та авторизація користувачів.
- Перегляд оголошень адміністрації гуртожитку №10.
- Спілкування між мешканцями.
- Створення заявок на ремонт.
- Календар подій гуртожитку.
- Довідкова інформація.
- Особистий кабінет мешканця.
